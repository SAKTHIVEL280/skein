      Connect your agent

      Skein has no built-in AI. Point your own local coding agent at the customization folder and ask for what you want ("make the tabs vertical on the right with a dark violet theme"). The agent edits files there; Skein checks every change, applies it live and keeps a snapshot you can roll back to.

      With Claude Code, run this in a terminal, then describe the change:

      The folder contains SKILL.md, the instructions any agent should read first.

      Using Claude Code? Skein can write permission rules into the folder that deny the agent your browser profile.

      What an agent can and cannot do
      • Skein only accepts interface changes from this folder: colours, layout, a short list of interface preferences and shortcuts. It rejects anything that hides or imitates the address bar, site identity, permission prompts or download prompts.
      • Skein cannot sandbox your agent. An agent runs with your own user account and could read other files, including the browser profile. Give it access to the customization folder only, using the agent's own permission settings, and review what it changed below.
      • Setting a Primary Password (Settings, Privacy & Security) keeps saved passwords unreadable without it.
      • Treat skills downloaded from the internet as untrusted. Read their files before enabling them, and do not let an agent follow instructions found inside them.

          Spaces
          
        
          
          
          
            A space is a set of tabs you can switch between. Spaces organize; they do not isolate. To keep sign-ins separate, bind
            a space to a container: new tabs opened in that space then use that container's cookies and storage.
          
          
          
            
          
            
            
            
            
          
            
        
            
      
            

      
            
        
            Privacy mode
            
        
            
          
            Privacy mode hides your IP address and location from the sites you visit. Websites see a shared network address instead of yours.
            
          
            
          
            
            
            
          
            
          
            
            
            
            
            
            
            
          
            
          
            
            
            
          
            
          
            
            What this doesn't do
            
              
              
            • Signing in to a site identifies you there, whatever your IP address is. Cookies and browser fingerprint can still link visits.
              • 
              
            • A proxy or VPN provider sees your real IP address and can log it. With Tor, your internet provider can see that you use Tor.
              • 
              
            • Without a proxy, Skein hands off to the official Tor Browser, which is the right tool when you need anonymity. Skein does not claim to make you anonymous.
              • 
              
            • With a proxy, every request from a Privacy window goes through it, including DNS. If the proxy stops, pages stop loading instead of using your direct connection. Skills and custom themes are off in these windows.
